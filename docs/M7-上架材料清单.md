# M7 · 上架材料清单

版本：0.6.0-m6（versionCode 6）
包名：`com.pingwu.app`
目标：把「可以拿去提交」的材料备齐；**是否提交、提交到哪个渠道，由作者决定**。

> 先看结论：材料这轮能备齐，但「个人上架」这件事卡在资质，不卡在材料。
> 医疗健康类目 + 在线 AI 功能，国内商店基本只收企业；之前已经确认过，《互联网药品信息服务资格证书》改备案后主体仍须是法人或其他组织。所以现实路线是：**自用 / 侧载 / GitHub 分发**，或者注册公司后再走商店。下面的材料两条路都用得上。

## 1. 渠道决策（先选路，再谈提交）

| 路线 | 能不能走 | 需要什么 | 建议 |
|---|---|---|---|
| 自用 / 给身边人装 | ✅ 现在就能 | APK + 安装说明 | 首选，先把真实使用跑起来 |
| GitHub / 网盘分发 | ✅ 现在就能 | release APK、README、隐私说明 | 第二选择；不承诺商店级合规 |
| 国内安卓商店（华为/小米/OPPO/vivo/应用宝） | ⚠️ 个人通道基本关闭 | 企业营业执照；医疗健康类目资质；AI 功能可能需算法/大模型备案 | 注册公司后再评估 |
| Google Play | ⚠️ 可个人开发者，但健康类需申报、全屏 Intent 有政策限制 | 开发者账号 $25；隐私政策 URL；Data safety 表 | 海外分发可考虑，仍建议先自用 |

**这轮不生成签名密钥、不提交任何商店**——按你之前「改动先留记录、可回滚」的习惯，签名和提交都等真机验收通过、你点头再说。

## 3. 权限与数据（审核会逐条看）

| 权限 | 用途 | 用户拒绝后 |
|---|---|---|
| CAMERA | 拍物品照片，作为完成凭证 | 无法拍照，只能看历史 |
| POST_NOTIFICATIONS | 到点提醒 | 收不到提醒（App 内会提示去开） |
| SCHEDULE_EXACT_ALARM | 准点响；没有则退到不精确闹钟，可能晚几分钟 | 提醒可能延迟 |
| USE_FULL_SCREEN_INTENT | 锁屏直接亮起验证页 | 退化为普通高优先级通知 |
| RECEIVE_BOOT_COMPLETED | 重启后重排提醒 | 重启后提醒可能不响，需打开 App |
| INTERNET / ACCESS_NETWORK_STATE | 仅用于「在线识别」（用户自备 Key，默认关） | 在线识别不可用，本机识别照常 |
| VIBRATE | 提醒震动 | 无震动 |

数据去向：

- 物品、提醒、待办、凭物照片：**只存本机**（Room + 应用私有目录）
- 在线识别开启时：照片与提示词发到**用户自己填的** OpenAI 兼容服务商；不经过开发者服务器
- API Key：只存本机 SharedPreferences，不上传
- 无账号、无云同步、无广告 SDK、无统计分析 SDK、不读取通讯录/位置/设备标识

完整说明见 [权限与合规说明](release/权限与合规说明.md)。

## 4. 合规风险清单

| 风险 | 说明 | 处置 |
|---|---|---|
| 医疗健康类目资质 | 国内商店医疗健康类目通常要企业资质；个人无法提供 | 自用/侧载，或注册公司后再提交 |
| 在线 AI 功能 | 若由开发者提供 Key，属于生成式 AI 服务，需备案；本 App 是用户自备 Key，App 只是工具 | 保持「用户自备 Key、默认关闭、明确提示照片离开本机」；隐私政策写清 |
| 全屏 Intent 政策 | Google Play 对 `USE_FULL_SCREEN_INTENT` 有使用限制（闹钟/通话类） | 若上 Play，改成「高优先级通知 + 点开全屏页」或申请豁免；国内商店一般不管 |
| 精确闹钟政策 | Google Play 对 `SCHEDULE_EXACT_ALARM` 有声明要求 | 提交时说明「用药提醒需要准点」，或用 `USE_EXACT_ALARM` 评估 |
| targetSdk | 2026 年商店普遍要求较新 targetSdk | 当前 targetSdk 36，满足主流要求 |
| 健康声明 | App 不提供诊断/用药建议，只做提醒与凭证 | 商店描述与隐私政策都写明「不构成医疗建议」 |

## 5. Release 构建与签名（等确认后再做）

当前只有 debug 包。正式分发需要 release 签名，步骤记录在这里，**没有执行**：

```powershell
# 1. 生成密钥（只做一次；密码自己保管，不要提交到仓库）
keytool -genkeypair -v -keystore pingwu-release.jks -alias pingwu `
  -keyalg RSA -keysize 2048 -validity 10000

# 2. 在 app/build.gradle.kts 增加 signingConfigs（密码从 local.properties 或环境变量读）
# 3. 构建
.\gradlew.bat :app:assembleRelease
.\gradlew.bat :app:bundleRelease   # 上 Google Play 用 AAB
```

注意：

- `pingwu-release.jks` 与密码**不进 git**（项目目前不是 git 仓库，也先别放公共目录）
- release 包要关掉 debug 测试入口（代码里已用 `BuildConfig.DEBUG` 包住，release 不会显示）
- 混淆：当前未开 minify；上架前可开，但要补 keep 规则（Room / OpenCV / ONNX）
