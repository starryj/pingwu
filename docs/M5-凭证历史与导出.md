# M5 凭证历史与导出

> 版本：`0.5.0-m5` · 日期：2026-11-13

## 这轮做了什么

1. **凭物照片墙**：凭物页新增「台账 / 照片墙」切换。照片墙按时间倒序、三列平铺全部凭物照片，每张下面标日期。
2. **凭物数据卡**：「我的」里显示本机照片数量与占用（例如 `4 张 · 536 KB`），并提供「导出 CSV」「清理旧照片」。
3. **CSV 导出**：把物品、待办、凭物合成一张表，写到 `cacheDir/exports/`，再通过 FileProvider 交给系统分享（Quick Share / Gmail / 文件等）。
4. **过期清理**：照片保留 180 天，导出缓存保留 7 天；「清理旧照片」手动触发，回调删除数量。

## CSV 格式

表头：

```
日期,时间,物品,剂量,应服数,状态,迟到,拍摄时间,照片,来源
```

- 按日期、时间倒序；同一天多次拍照会各占一行（一条凭物一行）。
- 状态：`已验证 / 漏拍 / 未拍 / 待拍`。
- 迟到：只有「已验证」写「是 / 否」，其余留空。
- 来源：`本机` / `在线`。
- 字段里出现逗号、引号、换行时按 CSV 规则加引号转义。
- 文件名：`凭物-导出-yyyyMMdd-HHmm.csv`。

## 已知限制

- 种子数据里的示例照片是资源 key（`pw_photo_1` 等），CSV「照片」列会直接显示这个 key；真实拍摄的照片显示文件名。
- 尚无「按时间筛选 / 搜索物品」；台账与照片墙暂按全量显示，数据多了再接分页或按月折叠。
- 照片真机拍摄的清晰度、ROM 对分享面板的影响仍等 真机 接上后补验。
