# M17 商标初筛（凭物 / MEMENTO）

> 结论先说：**正式的商标检索做不了**——这台机器走不通商标局的可查通道，
> 而「初筛」也不该拿来当法律结论。下面是能确定的部分、风险判断，以及你（或代理）
> 去查时需要查什么。

## 一、为什么这次没查成

| 通道 | 结果 |
| --- | --- |
| `web_search` 工具 | HTTP 401 —— 搜索服务的 API Key 失效（配置问题，非网络） |
| Bing（网页抓取） | 只返回无关结果（WPS 下载页），没有商标数据 |
| 中国商标网（sbj.cnipa.gov.cn 商标查询） | 需要图形验证码 + 会话，脚本抓不到「是否近似」的判定结果 |

商标检索的核心不是「搜到几条同名」，而是**近似判断**（字形、读音、含义、指定商品是否类似）。
这件事只能靠商标局的官方检索系统，或者付费的代理/数据库（如标库网、权大师）人工看。

## 二、能确定的事

1. **「凭物」是通用汉语词**（《现代汉语》：凭借之物）。作为商标，
   在第 9 类（计算机软件）、第 42 类（软件服务）这类「跟商品本身功能直接相关」的类别上，
   审查员很可能以**缺乏显著性**（《商标法》第作者条第一款第（三）项：其他缺乏显著特征的标志）
   提出驳回。
2. 因此单纯申请「凭物」两个字的成功率不高；更稳的是**组合标**：
   - 「凭物 MEMENTO」（中英组合，整体有识别力）
   - 图形标：猫坐纸箱那枚 logo（图形标显著性最好，且和 App 图标一致）
3. 不注册也能用：自用 / 侧载 / GitHub 发布都不需要商标；只有**要上架、要防别人抢注、
   要投诉侵权**的时候才需要。
4. 目前的上架路线本身还卡在资质（医疗健康类目需要企业主体），
   商标优先级低于这件事。

## 三、建议你（或代理）按这个清单查

检索词（每个都要查，含简体、拼音、英文）：

- 凭物
- 凭物 MEMENTO
- PINGWU / PING WU
- MEMENTO（单独查，这词在文具、软件类目很可能已被注册）

类别：

| 类别 | 为什么查 |
| --- | --- |
| 第 9 类 | 可下载的计算机应用软件（App 本体） |
| 第 42 类 | 软件即服务、计算机软件设计（如果以后做云端） |
| 第 44 类 | 医疗健康服务（如果以后沾健康管理） |
| 第 35 类 | 广告、商业管理（应用商店/推广相关，常见防御性注册） |

要看的字段：申请号、申请人、申请日期、状态（有效/无效/驳回中）、**类似群**、是否近似。

## 四、下一步（按性价比排）

1. **现在什么都不用做**——名字先用着，等真要上架再注册商标（组合标 + 图形标一起报）。
2. 想省钱的初筛：中国商标网「商标网上查询 → 商标近似查询」，选第 9 类，
   分别输入「凭物」和「MEMENTO」，把结果截图存下来。
3. 想省事的：找代理做一次检索报告（几百块），让他们出「可否注册」的意见。
4. 无论哪种，**先别在应用商店标题里把「凭物」写成主品牌**，避免以后改名成本——
   可以先用「凭物 · 到点提醒，拍一下才算做过」这种描述性用法。
