# 凭物 · 应用描述（商店文案）

## 基本信息

- 应用名称：凭物
- 副标题 / 一句话：拍到那件东西，才算真的做过。
- 分类建议：健康（用药提醒）/ 生活（习惯与备忘）
- 关键词：提醒、用药提醒、习惯、打卡、拍照、备忘、凭物、凭证

## 短描述（≤80 字）

把怕忘的事绑在一件看得见的东西上。到点提醒，拍下它才算完成——不是打卡，是看见。

## 长描述

有些事不是不想做，是到点就忘了。

凭物把每一件怕忘的事，绑在一件看得见的东西上：一板药、一个水杯、一只垃圾袋。到点它提醒你，你拍下那件东西，这件事才算完成。

**怎么用**

1. 建一个物品：写下名字、每次多少、每天几点。
2. 到点收到提醒，点开就是验证页。
3. 按提示拍一张：把东西拍进框里。
4. 对上了，收下一张完成卡；凭物里会留下这张照片和时间。

**为什么是拍照**

打卡可以点一下就算，拍照得真的看见。凭物不评价你，只帮你留下「这件事确实发生过」的证据。照片只存在你的手机里，不上传、不分析、不排行。

**可以看回自己的记录**

凭物页有台账，也有照片墙；可以按天展开，也可以按物品翻它自己的全部照片。想留档时，可以导出 CSV。

**关于在线识别（可选，默认关闭）**

如果你想让它更懂画面，可以在「我的 → 在线识别」里填自己的 API Key（OpenAI 兼容），开启后由模型判断这张照片算不算完成。开启前会明确提示：照片会发送到你填的服务商。不开启时，全部在本机完成。

**说明**

凭物是提醒与凭证工具，不提供诊断、用药建议或剂量推荐。用药请遵医嘱。

## 更新说明（版本 0.6.0-m6）

- 到点提醒支持锁屏全屏验证页（Android 14+ 需在系统设置里允许）
- 同一时间多个待办会逐条提醒，不再只提醒第一条
- 凭物页支持「台账 / 照片墙」切换
- 我的页可导出 CSV、清理旧照片
- 在线识别开启后，由模型参与判断是否通过
