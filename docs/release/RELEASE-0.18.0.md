## 凭物 0.18.0

首个面向应用商店的版本。包名 `com.pingwu.app`，versionCode 39，minSdk 26（Android 8.0+），targetSdk 36。

### 新增

- **首启隐私说明页**：第一次打开先说明数据怎么处理，同意后才申请权限、才读写数据。
- **关于页**：新增备案号与「隐私政策 → 查看全文」入口，政策托管在 `https://pingwu-privacy.eleven-locus.com/privacy`。
- `build.cmd`：一条命令完成构建，自动带好 JDK 路径。

### 变更

- 文案统一为「物品 / 数量」口径，不再使用与用药相关的措辞。
- 商店截图更换为真机 1080×1920 演示（钥匙、门禁卡、工牌）。

### 安装包

- `pingwu-0.18.0-arm64.apk`：只含 `arm64-v8a` 与 `armeabi-v7a`，不含模拟器 ABI。Android 8.0 及以上可直接安装。

### 已知限制

- 到点提醒的全屏验证页在 Android 14+ 需要用户手动允许。
- 在线识别为实验功能，默认关闭，需自行填写第三方服务地址与密钥。
