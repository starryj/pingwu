## 凭物 0.17.4

到点提醒这条路上，把「解锁在用的时候到底怎么提醒」这件事做通了。

### 这一版修了什么

**1. 解锁状态下，到点页真的会盖出来**

Android 14 起，全屏通知只对来电和闹钟放行；你在用手机的时候，凭物原本只能给你一条横幅，整页到点提醒会被系统静默换成小通知。这一版改成自己画一层：系统照旧发通知、响铃、震动，同时用悬浮窗把整页盖出来。

需要你在「我的 → 到点提醒」里允许一次**「显示在其他应用上层」**。不给也能用，只是解锁时仍然只收到通知。

**2. 点通知不再闪退**

以前点通知会直接退出——导航图还没装好就跳拍照页，抛异常把进程带走了。现在等导航就绪再跳。

**3. 到点通知的类别改成「闹钟」**

不然 Android 14+ 会把全屏权限当成没给。

### 下载

- `pingwu-0.17.4-arm64.apk`（约 58 MB）
- SHA-256：`239de8a30573c9e004304097fa718de152af9c717fa465690892568f85aff2ae`
- 适用于 arm64-v8a / armeabi-v7a 的 Android 8.0（API 26）及以上

### 安装

1. 下载 APK，点开安装（小米 / 红米需要在开发者选项里打开「USB 安装」之外的「安装未知应用」许可）
2. 首次打开给相机、通知权限
3. 建议在系统里补三项，不然到点提醒可能不响：
   - 自启动
   - 省电策略 → 无限制
   - 锁屏显示 + 后台弹出界面

> 这一版换了签名（和 0.17.2 的 Release 同一个密钥，但与更早的 debug 包不同）。如果手机上装的是 debug 包，需要先卸载再装，会清掉本地数据。

### 已知限制

- 照片只存在本机，卸载即丢；「我的 → 凭物数据」里可以导出 CSV
- 在线识别是可选的，默认关闭；开启后照片会发到你填的模型服务
- 到点提醒的可靠性最终取决于系统省电策略，小米 / 红米务必给「无限制」
