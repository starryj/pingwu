## 1. 我们收集什么

凭物默认不收集任何个人信息，也没有账号系统。

**存在你手机里的数据：**

- 你创建的物品名称、剂量、每次颗数、提醒时间
- 每天的待办与状态（待拍 / 已验证 / 漏拍）
- 你拍的照片，以及拍摄时间
- 你的主题选择、验证窗口设置
- 如果你填了在线识别的 API Key，它也只存在本机

以上数据都在应用私有目录 / 本地数据库里，不会自动上传到开发者服务器。

**在线识别开启时：**

- 你拍的照片会以 base64 形式发送到**你自己填写的** OpenAI 兼容服务商
- 同时发送一段固定提示词，包含物品名称与应服数量，用于让模型判断是否通过
- 开发者不运营中转服务器，不接收、不存储这些照片和 Key
- 服务商如何处理数据，取决于你选择的服务商及其隐私政策

**我们不收集：**

- 姓名、手机号、通讯录、位置、设备标识符
- 广告标识、崩溃统计、使用行为埋点
- 没有集成任何第三方广告或分析 SDK

## 2. 权限与用途

| 权限 | 用途 | 拒绝后的影响 |
|---|---|---|
| 相机 | 拍摄物品照片作为完成凭证 | 无法拍照验证 |
| 通知 | 到点提醒 | 收不到提醒 |
| 精确闹钟 | 尽量准点提醒 | 提醒可能晚几分钟 |
| 全屏通知（Android 14+） | 锁屏直接亮起验证页 | 退化为普通通知 |
| 开机广播 | 重启后恢复提醒 | 重启后提醒可能不响 |
| 网络 | 仅在线识别时使用 | 在线识别不可用，本机功能正常 |
| 震动 | 提醒时震动 | 无震动 |

---

## 3. 数据保存与删除

- 照片存在应用私有目录，默认保留 180 天；可在「我的 → 凭物数据 → 清理旧照片」手动清理
- 删除某个物品时，与它相关的提醒会停止；历史凭物可在「我的 → 清空凭物」里删除
- 导出的 CSV 在你主动分享前只存在应用缓存，7 天后自动清理
- 卸载 App 会删除应用私有目录中的全部数据（包括照片和 Key）

---

## 4. 数据安全

- 数据存放在 Android 应用私有目录，其他应用无法直接读取
- 在线识别的 Key 存在本机 SharedPreferences，不上传
- 传输到第三方服务商时使用 HTTPS（由你填写的服务商地址决定）
