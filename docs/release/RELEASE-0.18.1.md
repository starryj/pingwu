## 凭物 0.18.1

夜间拍照补一个开关。包名 `com.pingwu.app`，versionCode 40，minSdk 26（Android 8.0+），targetSdk 36。

### 新增

- **拍照页的闪光灯开关**：取景框右上角一枚胶囊按钮，「闪光灯 · 开 / 关」一键切换。
  用的是手电筒常亮，不是快门瞬间闪一下——夜里取景框是黑的，常亮才好一边看一边摆位置。
- 选择会记住：这次开着，下次进拍照页还是开着，并把灯直接点亮。
- 离开拍照页自动关灯，不会回到桌面还亮着。

### 变更

- 版本号 39 → 40，`0.18.0` → `0.18.1`。功能与 0.18.0 一致，只有这一处新增。

### 已知

- 没有闪光灯的设备（前置摄像头、部分平板）不显示这个按钮。
- 解锁状态下到点只弹横幅是 Android 14 之后的系统限制，凭物用悬浮层解决，
  需要允许一次「显示在其他应用上层」（我的 → 到点提醒）。
