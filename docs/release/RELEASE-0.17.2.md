## 装法

1. 下载上面的 APK，点开安装；
2. 系统提示「未知来源」时，允许浏览器或文件管理器安装应用；
3. 首次打开会申请相机与通知权限，都允许才能正常提醒与拍照。

小米 / 红米用户还需要在系统设置里给凭物打开三项，否则到点可能不弹：

- 自启动
- 省电策略 → 无限制
- 权限 → 其他权限 → 后台弹出界面、锁屏显示

## 这个版本能做什么

- 今日 / 物品 / 凭物 / 我的 四个页面；深墨与纸白两套主题，开屏跟随主题
- 一件物品可以绑多块「认得的样子」，拍照时按片数核对 + 本机模板比对，对不上会拒绝并说明原因
- 可选在线视觉模型识别：自带 Key、OpenAI 兼容端点、默认关闭，打开时照片会发到你填的服务商
- 到点全屏提醒，闹钟音量响铃 + 振动，铃声可选系统铃声或自己传
- 凭物按天展开当天照片，物品详情里能看这件东西的全部照片
- 已删除的记录可以长按多选彻底删除；「我的 → 凭物数据」能按物品挑着删
- 完成卡与票根式凭物回执；CSV 导出；旧照片清理与孤儿照片对账

## 已知限制

- 首版只做了「东西在不在画面里」和「片数对不对」，不能证明你真的吃了药，也不能证明事情已经做完
- 本机识别对光线、遮挡、反光敏感，拍的时候尽量把东西摊开、别叠在一起
- 系统省电策略可能让提醒晚到，重要的事请留余量

## 隐私

照片只存在手机的应用私有目录里，不上传、不统计、不要账号。只有你自己打开在线识别时，照片才会发给你填的那个服务商。
