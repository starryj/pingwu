## 使用注意

- 商店一般要求 3–8 张；建议用 01/02/03/04/05 五张。
- 当前截图来自模拟器，且含测试数据（TestPill、示例照片）。正式提交前建议：
  1. 在真机上重新截一遍；
  2. 清掉 TestPill 和调试照片，换成真实使用记录；
  3. 检查时间、通知栏无敏感信息。
- 部分商店要求 16:9 或 9:16，1080×1920 是常用规格；如被拒再按目标商店要求重出。
- 图标（512×512 PNG）尚未导出，需要从设计稿生成；现有 `ic_launcher` 是矢量自适应图标。
