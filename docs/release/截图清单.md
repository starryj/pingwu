## 使用注意

- 商店一般要求 3–8 张；建议用 01/02/03/04/05 五张，06 作补充。
- 截图内均为日常物品（钥匙、门禁卡、工牌），不含药品、医疗、真实个人信息；通知栏已清空。
- 拍完后真机已还原：分辨率 1440×3200、密度 560、通知横幅恢复，App 数据回滚为原库。
- 部分商店要求 16:9 或 9:16，1080×1920 是 9:16 常用规格；如被拒再按目标商店要求重出。
- 图标 512×512 PNG 见 `docs/brand/ic_launcher-play-512.png`（自适应图标另见 `ic_launcher` 矢量源）。
