# M6 · 真机 真机验收清单

版本：0.6.0-m6（versionCode 6）
目标机：测试机 中国版（HyperOS 3 / Android 16）
原则：模拟器先跑通，真机只验「模拟器验不了/不像真机」的部分；每条都留证据（截图或日志），失败就记下来，不现场猜。

## 0. 准备

### 0.1 手机上先开这些（HyperOS 特有，缺一个提醒就可能不响）

按顺序走一遍「设置」：

1. **自启动**：设置 → 应用设置 → 应用管理 → 凭物 → 自启动 → 允许
2. **省电策略**：同上页面 → 省电策略 → 无限制
3. **通知**：设置 → 通知与控制中心 → 凭物 → 允许通知；再打开「锁屏通知」「悬浮通知」
4. **相机权限**：设置 → 应用设置 → 凭物 → 权限管理 → 相机 → 允许
5. **闹钟和提醒**：设置 → 应用设置 → 凭物 → 特殊权限 → 闹钟和提醒 → 允许
   （Android 14+ 若看到「全屏通知」也一并允许；没有这一项就跳过）
6. 可选：设置 → 应用设置 → 凭物 → 后台弹出界面 → 允许

### 0.2 电脑这边

```powershell
$adb = "<Android SDK>\platform-tools\adb.exe"
& $adb devices                 # 看到设备再继续
& $adb install -r app\build\outputs\apk\debug\app-debug.apk
& $adb shell am start -n com.pingwu.app/.MainActivity
```

抓日志（出问题时用）：

```powershell
& $adb logcat -c
& $adb logcat | Select-String "com.pingwu.app|AlarmManager|NotificationService"
```

## 8. 已知限制（不是 bug，验收时别当故障）

- 照片只能证明「东西在」，不能证明「已经吃了」——全屏页和结果页都写了这句话。
- 在线识别需要用户自备 Key；照片会发到用户填的服务商，默认关闭。
- 国产 ROM 可能压后台、延后闹钟；已做不精确闹钟兜底，但可能晚几分钟。
- 全屏验证页目前用内置示例照片；真机拍到的最新照片展示留到 M7 之后。
- 没有做账号/云同步，全部数据在本机。

## 11. 真机 真机实测记录（2026-11-13，测试机 / Android 16 / SDK 36 / 1440×3200）

设备信息：型号 23113RKC6C，HyperOS 3（Android 16），无线 adb 连接。

### 11.1 安装与启动
- 首次 `adb install` 报 `INSTALL_FAILED_USER_RESTRICTED`；在开发者选项里打开「USB 安装」后成功。
- `am start -W` 冷启动 TotalTime 1164ms（0.6.0-m6，debug 包）。
- 结果：**通过**。

### 11.2 界面
- 首页、物品页、凭物页（台账/照片墙）、我的页、拍照页、全屏验证页均在 1440×3200 上正常显示，内容不溢出；状态栏与页眉不再重叠。
- 截图：`docs/shots/k70-home.png`、`k70-camera.png`、`k70-done.png`、`k70-permissions.png`。

### 11.3 拍照与判定（真实相机）
- 相机预览正常；顶栏显示「在线判定未开启 / 本机检测」。
- 对着桌上两粒阿莫西林胶囊按快门：保存照片成功，本机检测报「本机看到 1 颗，应拍 2 颗」，界面正确显示「这次没算通过：本机看到 1 颗，和应服的 2 颗对不上。」——两粒胶囊贴在一起被算成一团，属于检测器的正常边界。
- 调试示例照片路径：4 颗 → 通过 → 完成卡显示真实落盘照片、`盐酸二甲双胍片 ×4`、12:16、「已存入今天的凭物」；凭物页变为 13 张 / 89% / 6 天 / 1 漏，11.13 行展开有真实照片。
- 截图：`docs/shots/k70-capture-real.png`、`k70-done.png`。

### 11.4 通知与锁屏全屏
- 调试「发测试提醒」：通知 id=7101、channel=pw_reminder、importance=4、category=reminder、vis=PUBLIC、带一个「去拍照」动作；通知栏样式正常（`docs/shots/k70-notification.png`）。
- 关键发现：只开系统「全屏通知」还不够，HyperOS 还要求 **「锁屏显示」** 与 **「后台弹出界面」** 两项权限（MIUI 权限管理 → 其他权限），否则全屏页不会弹出，只会响通知。
- 三项都允许后，锁屏状态下 5 秒测试提醒成功点亮屏幕并直接弹出全屏验证页（`docs/shots/k70-lockscreen.png`）；「稍后」可关闭。
- App 已加引导：我的页「锁屏全屏」按钮在小米/红米上会跳到 MIUI 权限编辑页，并在卡片里提示需要「后台弹出界面」。版本 0.6.1-m6。

### 11.5 尚未在真机完成

- 重启后 BootReceiver 是否恢复排程、长时后台闹钟、真实到点的锁屏全屏（3.6–3.10）。
