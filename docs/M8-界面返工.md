## 六、0.8.2：底栏真因 + B 版收据

### 1. 底栏「今日」不跳的真因

复现路径（作者给的线索）：从今日点「全部凭物」进到凭物页，再点底栏其他 tab 都正常，唯独点「今日」停在凭物页。

在模拟器上按这条路径稳定复现：`input tap 939 1117`（全部凭物）→ `input tap 135 2286`（今日），logcat 显示
`tap target=home from=evidence` → `after navigate current=evidence`：点击收到了，导航没生效。

原因在旧写法：

```kotlin
nav.navigate(target) {
    popUpTo(Routes.HOME) { saveState = true }
    launchSingleTop = true
    restoreState = true
}
```

`saveState` 把当前栈存起来，`restoreState` 又马上恢复；当 target 正好是 `popUpTo` 的目的地 `HOME` 时，
恢复回来的就是刚离开的那个栈，所以界面停在原处。之前 0.8.1 加的「去 ripple、加宽可点区」都是对症不对因。

修法（`ui/PingWuRoot.kt`）：

```kotlin
onSelect = { target ->
    if (target != route) {
        val popped = nav.popBackStack(target, inclusive = false)
        if (!popped) {
            nav.navigate(target) {
                popUpTo(Routes.HOME) { inclusive = false }
                launchSingleTop = true
            }
        }
    }
}
```

先在返回栈里找 target（tab 之间跳转本来就该是「回退」），找不到才前进并清掉中间页；不再用 `saveState/restoreState`。

修复后模拟器导航矩阵 10/10 通过：全部凭物→凭物、今日→今日、物品→物品、今日→今日、凭物→凭物、今日→今日、我的→我的、凭物→凭物、物品→物品、今日→今日。

踩坑记录：临时用 `nav.currentBackStack.value` 打栈，`lintDebug` 报 `RestrictedApi`
（`NavController.getCurrentBackStack can only be called from within the same library group`）直接 BUILD FAILED，已改成只打 `nav.currentDestination?.route`。
